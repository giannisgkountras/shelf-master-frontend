# ShelfMaster Frontend

## Overview

This application provides a basic structure with pages for managing products, warehouses, customers, suppliers, and employees.

## Installation

To get started

1. Clone the repository and install the dependencies:

```bash
git clone <repository-url>
cd project-directory
npm install
```

2. Create an env file containing the following

```env
VITE_API_BASE_URL=your-api-url
```

## Usage

Run the development server:

```bash
npm run dev
```

The application will be available at http://localhost:5173/ (default port).
